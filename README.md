# vedic-math-hybrid-kt
Hybrid Vedic Math AI: rule-based sutras (Urdhva-Tiryagbhyam, Nikhilam, Yavadunam) plus RF classifier that cleans noisy skill tags and LSTM knowledge tracing with Focal Loss. Generates 10k problems, simulates student sequences, and tracks mastery even when labels are messy. Research + interactive calculator in one place.
